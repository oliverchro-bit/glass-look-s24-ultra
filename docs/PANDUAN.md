# Panduan Glass Look iOS di Galaxy S24 Ultra (One UI 9, gratis)

Target: tampilan mendekati Liquid Glass iOS 26 tanpa app berbayar.

Batasan:
- Blur dan refraksi real-time iOS tidak bisa ditiru 100%. Hasil realistis sekitar 70-80%.
- Nama menu di One UI 9 bisa beda dari tulisan di sini. Kalau menu tidak ketemu, kasih tau nama menu yang kamu lihat, panduan disesuaikan.
- Hanya pakai fitur bawaan Samsung dan Good Lock (gratis).
- Jangan install app "iOS launcher" atau "iPhone theme" dari sumber tidak jelas. Banyak yang penuh iklan dan minta izin berlebihan.

Cara kerja: kerjakan satu langkah, cek hasilnya, lapor ke Claude, lanjut langkah berikutnya.

---

## Langkah 1. Wallpaper dan warna dasar
Efek kaca terlihat hanya kalau background punya warna dan gradasi. Wallpaper polos membuat hasilnya datar.

1. Pilih wallpaper abstrak gradasi lembut (biru, ungu, pink, atau oranye), tanpa detail ramai.
2. Settings > Wallpaper and style > pasang untuk Home dan Lock screen.
3. Di menu yang sama, Color palette > pilih warna yang cocok dengan wallpaper.
4. Pakai mode Light dulu (Settings > Display > Light). Kaca terlihat paling jelas di mode terang.

Cek: ikon dan widget terbaca jelas di atas wallpaper.

## Langkah 2. Bentuk ikon
1. Buka Good Lock > Theme Park (kalau belum ada, install dari dalam Good Lock).
2. Buat tema baru > Icon > pilih bentuk rounded square (squircle) dan ukuran sedikit lebih besar.
3. Simpan dan Apply.

Cek: semua ikon app seragam bentuknya (squircle).

Ikon warna-warni ala iOS: di Galaxy Store > Themes > Icons, cari "glass" atau "iOS 26". Pilih yang gratis, rating tinggi, dan sudah banyak unduhan. Cek review dulu. Kalau ragu, lewati dan pakai ikon bawaan.

## Langkah 3. Home screen ala iOS (Home Up)
1. Good Lock > Home Up > aktifkan.
2. Home screen settings > Home screen layout > pilih Home screen only (tanpa app drawer, seperti iOS).
3. Grid: 4 kolom x 6 baris.
4. Dock: 4 ikon.
5. Folder: pilih style kotak transparan.

Cek: tidak ada tombol app drawer, ikon tersusun 4 kolom.

## Langkah 4. Quick panel dan notifikasi (QuickStar)
1. Good Lock > QuickStar > aktifkan.
2. Background panel: pakai blur dan transparansi tinggi (geser slider transparansi ke sekitar 60-70%).
3. Warna panel: putih/abu muda semi-transparan.
4. Status bar: ikon jam di kiri, indikator di kanan (menyesuaikan opsi yang ada).

Cek: saat swipe turun, panel terlihat seperti kaca buram dan wallpaper tembus.

## Langkah 5. Lock screen
1. Settings > Lock screen > Clock style > pilih jam besar, font tebal, rata tengah.
2. Warna jam: putih atau mengikuti wallpaper.
3. Notifications > pilih mode Details (kartu notifikasi), transparansi sesuai opsi.
4. Opsional: Good Lock > LockStar untuk atur posisi jam, widget, dan shortcut.

Cek: lock screen terlihat bersih seperti iOS.

## Langkah 6. Widget transparan
1. Tekan lama widget bawaan > Settings (atau Widget settings) > transparansi sekitar 50-70%.
2. Pilih widget cuaca, jam, kalender, dan baterai. Susun satu gaya, jangan campur banyak ukuran.
3. Sudut widget membulat (default One UI sudah membulat).

Cek: widget tembus ke wallpaper, tidak ada kotak solid.

## Langkah 7. Keyboard
1. Settings > General management > Samsung Keyboard settings > Style and layout > Keyboard theme / Transparency.
2. Pilih tema terang, transparansi tinggi, tanpa border tombol.

Cek: tombol keyboard terlihat seperti kaca terang.

## Langkah 8. Font, animasi, dan detail akhir
1. Font: Settings > Display > Font size and style. Pilih font sans-serif bersih. Font Apple (SF Pro) tidak bisa dipasang resmi, jadi pakai yang paling mirip dari daftar gratis.
2. Animasi: Settings > Accessibility > Visibility enhancements, pastikan Remove animations dalam keadaan mati.
3. Settings > Display > Navigation bar > Swipe gestures (pengganti tombol, mirip iOS).
4. Settings > Display > Screen resolution: WQHD+ supaya blur lebih halus.
5. Restart HP.

Cek: tampilan konsisten, tidak ada elemen yang solid dan kontras dengan tema.

## Rollback
- Theme Park: pilih tema default atau tekan Reset di dalam modul.
- Home Up dan QuickStar: nonaktifkan modul, kembali ke pengaturan Samsung.
- Backup dulu: Settings > Accounts and backup > Back up data > Home screen layout.
